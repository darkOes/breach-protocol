# Breach Protocol

> A Cyberpunk-style hacking minigame that runs in the browser.

**▶ Live demo: https://darkoes.github.io/breach-protocol/**

## Features

- Code matrix with alternating row/column picks, a limited buffer and three daemons to upload`n- Every puzzle is generated from one valid path, so a full breach is always possible`n- Trace timer, 3 difficulty levels, keyboard support, local stats

## Notes

Pick a code in the top row, then alternate: column, row, column... Fill the buffer with the daemon sequences before the trace completes.

## Tech

Single `index.html` file. Vanilla HTML, CSS and JavaScript, no dependencies, no build step. Hosted on GitHub Pages.

Run locally: open `index.html` in a browser.
